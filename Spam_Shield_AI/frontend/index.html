PROJECT OVERVIEW

About this project

A practical text-classification system built with Python and machine learning.

✦

Spam Message Classifier

The application evaluates text messages and estimates whether they resemble spam or normal messages. The prediction is produced by a supervised machine-learning pipeline.

Technologies used

🐍
PythonCore language
🧠
Scikit-learnMachine learning
🔤
TF-IDFText features
⚡
FastAPIPrediction API
🌐
NetlifyWeb frontend hosting

Classification workflow

Dataset→Text cleaning→TF-IDF→Logistic Regression→Prediction

Predictions are estimates and can be incorrect. Do not rely on the classifier as the only filter for important messages.
